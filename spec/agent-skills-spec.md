# Skill 编写规范

格式遵循 [Agent Skills 标准](https://agentskills.io/specification)。

## 目录与字段

每个技能独立放在 `skills/<skill-name>/`，入口为 `SKILL.md`。参考资料和素材按需放入该目录，以相对路径引用。

`SKILL.md` 以 YAML frontmatter 开头，后接 Markdown 正文；完整起点见[模板](../template/SKILL.md)。

| 必填字段 | 约定 |
| --- | --- |
| `name` | 与目录名一致，1–64 个字符；仅小写字母、数字和连字符；不以连字符开头或结尾，不使用连续连字符。 |
| `description` | 1–1024 个字符，说明做什么、何时使用；必要时写明不适用的相近场景。 |

## 正文

- 写明必要输入、关键操作、结果要求和验证方法。
- 保留影响执行决策的业务规则，避免重复常识；较长资料按需链接。
- 需要特定工具或环境时注明依赖，避免作者机器上的绝对路径。
- 提交前删除占位内容，检查引用文件，并用真实任务验证。
